🍃 银杏AI

版本 1.0 · 2026-07-10
📖 关于项目

银杏AI 是一款轻量级智能对话助手，由 System_VM_D62E 独立开发。 项目始于 2026年5月，从桌面版迁移至 Web 端，经历了深度思考机制设计、 液态玻璃界面打磨、多轮稳定性优化，最终形成现在的 1.0 版本。

核心能力：
• 💬 智能对话 + 深度思考（思维链展示）
• 👁️ 视觉识别（上传图片让AI解读）
• 🎨 图像生成（文生图 / 图生图）
• 🎬 视频生成（文生视频 / 图生视频，支持短/中/长三档时长）
• ⏱️ 视频进度轮询 + 预估剩余时间
• 🔍 实时联网搜索（DuckDuckGo）
• 🛠️ 实用工具：时间、日期、天气、计算、密码生成、倒计时、日期差
• 🎨 液态玻璃 UI + 主题色自定义

🛠️ 技术栈
Flask 智谱 GLM-4-Flash Agnes Vision Agnes Image Agnes Video V2.0 原生 JavaScript 液态玻璃 CSS
