🔒 隐私政策

最后更新：2026年7月10日
1. 我们收集的信息

银杏AI 仅收集您主动提供的对话内容、上传的图片以及图像/视频生成请求，以完成问答、视觉识别、图像生成和视频生成功能。所有对话数据存储在您本地设备的 `ginkgo_conversations.json` 文件中，不会主动上传至任何远程服务器（除必要的 API 调用外）。

2. 数据存储
  • 对话记录：保存在您本地的 JSON 文件中，您可以随时在设置中「清空所有对话历史」。
  • 设置偏好：主题、字体大小等设置保存在浏览器的 localStorage 中，仅存在于您的设备上。
3. 第三方服务

当您使用智谱 AI 相关功能（对话、深度思考等）时，您的消息会被发送至智谱 API 进行处理。当您使用视觉识别、图像生成或视频生成功能时，您上传的图片或生成的请求会通过 Agnes API 进行处理。请参阅 智谱AI 的隐私政策 以及 Agnes AI 的隐私政策 了解其数据处理方式。天气查询功能使用 wttr.in 的公开 API，仅传输城市名称。

4. 数据安全

由于所有对话数据均存储在本地，数据的物理安全取决于您设备的安全状况。建议您定期备份重要对话（使用「导出对话」功能），并保持操作系统和浏览器的更新。

5. 您的权利
  • 您可以随时查看、编辑或删除自己的对话记录。
  • 您可以通过「导出对话」功能导出完整对话内容。
  • 您可以在设置中一键「清空所有对话历史」。
6. 隐私政策更新

本隐私政策可能不时更新。更新后的版本将在本页面发布，并更新页面顶部的「最后更新」日期。建议您定期查阅。

7. 联系我们

如对本隐私政策有任何疑问，可通过 B站 System_VM_D62E 联系开发者。
